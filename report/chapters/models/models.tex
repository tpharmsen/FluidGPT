\chapter{Models}\label{ch:models}

This chapter presents the model architectures developed for spatiotemporal fluid dynamics prediction, motivated by the challenges of generalisation, temporal stability, and computational efficiency. We introduce a shared backbone combining a hierarchical Swin Transformer with a novel space-then-time attention mechanism within a UNet-style encoder-decoder structure. This architecture is used for both the deterministic model and a flow-matching model. This shared design allows for a controlled comparison between the two approaches, isolating the effects of deterministic versus probabilistic formulations while holding architectural capacity fixed.

\section{Challenges}

\subsection{Generalisation}

As the goal of this work is to develop a foundation model for fluid dynamics, the ability to generalise across different flow regimes is a critical requirement. This requires the model to learn representations that are not specific to any single dataset or flow condition, but rather capture the underlying physics of fluid dynamics in a way that can be applied to a wide range of scenarios. The underlying backbone achitecture must be natively designed to capture the spatiotemporal structure of fluid dynamics, and the generative modelling strategy must be able to handle the inherent stochasticity and sensitivity of turbulent flows.

\subsection{Temporal Stability}

As auto-regressive models are prone to compounding errors with each new rollout iteration, ensuring temporal stability is crucial for maintaining the accuracy of predictions over extended time horizons. Ideally the model should hav a built-in mechanism to mitigate error accumulation, such as using a longer range of input states to condition the model on a longer history of the systems evolution, or using a probabilistic formulation that can capture the distribution of possible future states. A models ability to capture a probabilistic view of the future system states is especially important for highly-turbulent sensitive systems.

\subsection{Efficiency}

As the model is intended to be trained on large-scale datasets, it must be designed to be sample-efficient, making effective use of each training example to learn robust representations. Additionally, the model must be computationally efficient, allowing for reasonable training and inference times even on large datasets. Especially during the training phase, the model must be able to process large batches of data in parallel, leveraging modern hardware accelerators such as GPUs and TPUs. This requires careful consideration of the model architecture, including the choice of attention mechanisms and other architectural elements, to balance computational cost with predictive performance.

\section{Overview of the Modeling Approaches}

This chapter introduces two modeling approaches for spatiotemporal fluid dynamics prediction: a deterministic generative model and a flow-matching generative model. To facilitate generalisation and efficient learning of spatiotemporal dynamics, a custom backbone is designed to capture both spatial and temporal dependencies. Both approaches share a common hierarchical Swin-based Transformer backbone with additional temporal information flow, implemented into a U-net style architecture to enable efficient multi-scale feature extraction and reconstruction. The differences in the two approaches lie in the conditioning strategy and generative modelling formulation. This similarity in models allows for a fair comparison of the two approaches while isolating the effects of the different generative modeling strategies. The deterministic model directly maps past velocity fields to future states, whereas the flow-matching model learns to conditionally flow a probability distribution.

\subsection{Original Swin Backbone}

The shared backbone is based on the original Swin Transformer \cite{liu2021swin}, which enables hierarchical feature extraction via shifted window self-attention. The shifted window mechanism allows for efficient local attention computation while maintaining the ability to capture long-range dependencies through hierarchical feature aggregation. The backbone consists of multiple stages, each containing several Swin Transformer blocks, with embedding merging layers between stages to reduce spatial resolution while increasing feature dimensionality and receptive field of applied attention mechanisms. The original Swin Transformer is designed for image classification tasks, but we adapt it for spatiotemporal fluid dynamics prediction by incorporating temporal information and modifying the attention mechanism to handle sequential data. Two challenges here are the extra temporal dimension and the need to return the processed data to the original spatial resolution instead of a classification output.

\subsection{Space-Then-Time Attention Backbone}

To incorporate temporal structure, we employ a custom space-then-time attention block. As temporal interactions, spacings and lengths are typically different than spatial interactions, it makes sense to factorize the attention mechanism into two seperate stages. Additionally, using a seperate attention stage for the temporal dimension allows for possibly more efficient and effective modeling of temporal dependencies, which is highly relevant for large-scale foundation training tasks. This is motivated by the block causal transformer BCAT, which concludes that a space-then-time attention mechanism is more efficient while negligibly affecting predictive performance compared to a spatiotemporal attention approach. \cite{liu2025bcat}

In practise, self-attention is first applied across spatial dimensions using the spatial windows of the original swin transformer block and subsequently in a perpendicular straight line across the temporal dimension. The corresponding attention masking strategy is illustrated in Figure~\ref{fig:BlockExplainer}. Multiple space-then-time attention blocks are used sequentially for smoother and more robust information spread.

\subsection{UNet-style Multi-scale Architecture}

The Swin Transformer backbone is embedded within a UNet-style encoder-decoder structure with skip connections \cite{ronneberger2015unet}. This design enables multi-scale feature extraction while preserving fine-grained spatial information, enhancing the models ability to capture complex spatial and temporal relationships. Additionally, the output dimensions of the model are the same size as the input, which is not the case with the classification output of the traditional Swin Transformer. Skip connections are implemented using ConvNeXt-style blocks \cite{Liu2022ConvNeXt}, which facilitate stable gradient propagation and information flow across resolution scales and encoder-decoder pathways. Additionally the ConvNeXt blocks allow for extra information aggregation from nearby spatial locations. Each level of the Unet focusses on a different spatial scale of information spread, with the deepest layer programmed for an spatial all-to-all attention mask.  


\subsection{Patch Embedding and Reconstruction}

At the input stage, the two-dimensional velocity field is partitioned into non-overlapping square patches. Each patch is projected into a latent embedding space using a learned 2-layer MLP. Static positional and temporal embeddings are added to each patch embedding to encode spatial and temporal structure. A single resulting embedding resembles both the x- and y-component of a part of the velocity field for a single time step.

At the output stage, the latent embeddings are projected back to the original velocity field dimension using a learned 3-layer MLP and reassembled into the full spatial grid.

\subsection{Hierarchical Patch Merging and Expansion}

As depth increases in the encoder, groups of four neighbouring patches/embeddings are merged into a single embedding with double size embedding dimension with a single dense connected layer. This operation progressively reduces spatial resolution while increasing receptive field size when used in combination with window attention mechanisms. This form of compression throughout the depth of the model also realises a form of regularization and generalisation. In the decoder, the reverse operation is applied to recover full spatial resolution.

\section{Mathematical Formulation}

This section provides the formal mathematical description of the core components shared by both models. We introduce notation, then derive the patch embedding, positional encoding, windowed cosine attention with continuous relative position bias, temporal attention, and the hierarchical patch merging/expansion operations.

\subsection{Notation}

Let $\mathbf{u} \in \mathbb{R}^{B \times T \times C \times H \times W}$ denote a batch of velocity fields, where $B$ is the batch size, $T$ is the number of time steps, $C=2$ is the number of velocity components ($u_x$, $u_y$), and $H \times W$ is the spatial resolution. Patch size is $(p_H, p_W)$, so the spatial patch grid has resolution $\hat{H} = H/p_H$ and $\hat{W} = W/p_W$, giving $N = \hat{H}\hat{W}$ patches per time step. The latent embedding dimension is $d$.

\subsection{Patch Embedding}

Each spatial patch $\mathbf{p}_{t,n} \in \mathbb{R}^{C \cdot p_H \cdot p_W}$ is extracted by unfolding the input field. The patch sequence for a single batch element is arranged as $\mathbf{P} \in \mathbb{R}^{T \times N \times (C \cdot p_H \cdot p_W)}$. Each patch is then projected into the latent space by a two-layer MLP:

\begin{equation}
    \mathbf{z}_{t,n} = W_2 \, \sigma\!\left(W_1 \, \mathbf{p}_{t,n} + \mathbf{b}_1\right) + \mathbf{b}_2,
    \qquad
    \mathbf{z}_{t,n} \in \mathbb{R}^{d},
\end{equation}

where $W_1 \in \mathbb{R}^{d_h \times (C p_H p_W)}$, $W_2 \in \mathbb{R}^{d \times d_h}$, and $\sigma$ is the activation function (GELU by default). The full encoded representation is $\mathbf{Z} \in \mathbb{R}^{B \times T \times N \times d}$.

The decoder projects back to pixel space with a symmetric three-layer MLP followed by spatial reassembly (folding):

\begin{equation}
    \hat{\mathbf{p}}_{t,n} = W_5 \, \sigma\!\left(W_4 \, \sigma\!\left(W_3 \, \mathbf{z}_{t,n}\right)\right) \in \mathbb{R}^{C \cdot p_H \cdot p_W}.
\end{equation}

\subsection{Spatiotemporal Positional Encoding}

Spatial position is encoded with factorised row and column embeddings. Let $\mathbf{e}^{\text{row}}_i \in \mathbb{R}^{d/2}$ and $\mathbf{e}^{\text{col}}_j \in \mathbb{R}^{d/2}$ be learned parameters for row $i$ and column $j$, respectively. A full spatial embedding at grid position $(i,j)$ is obtained by concatenation:

\begin{equation}
    \mathbf{s}_{i,j} = \left[\mathbf{e}^{\text{row}}_i \;\|\; \mathbf{e}^{\text{col}}_j\right] \in \mathbb{R}^{d}.
\end{equation}

A separate learned temporal embedding $\mathbf{e}^{\text{time}}_t \in \mathbb{R}^{d}$ encodes the time step. The combined positional encoding added to each token is:

\begin{equation}
    \mathbf{Z}_{b,t,n,\cdot} \leftarrow \mathbf{Z}_{b,t,n,\cdot} + \mathbf{s}_{i(n),j(n)} + \mathbf{e}^{\text{time}}_t,
\end{equation}

where $i(n)$ and $j(n)$ denote the row and column indices of patch $n$ in the spatial grid.

\subsection{Windowed Cosine Normalized Attention with Continuous Relative Position Bias}

\paragraph{Window partitioning.}
The spatial token map at a given level is reshaped to $(\hat{H}, \hat{W})$ and partitioned into non-overlapping windows of size $w \times w$. For a shifted-window block, the map is first cyclically shifted by $(\lfloor w/2 \rfloor, \lfloor w/2 \rfloor)$ pixels before partitioning, and the shift is reversed afterwards. Each window contains $M = w^2$ tokens and is processed independently, yielding an effective batch of $\frac{\hat{H}\hat{W}}{w^2}$ windows per sample per time step.

\paragraph{Query, key, value projection.}
For tokens $\mathbf{X} \in \mathbb{R}^{M \times d}$ within a window, queries, keys, and values are computed as:

\begin{equation}
    \mathbf{Q} = \mathbf{X} W^Q, \quad
    \mathbf{K} = \mathbf{X} W^K, \quad
    \mathbf{V} = \mathbf{X} W^V,
\end{equation}

where $W^Q, W^K, W^V \in \mathbb{R}^{d \times d}$. Separate additive biases $\mathbf{b}^q$ and $\mathbf{b}^v$ are used for queries and values. No bias is applied to keys, following the improved Swin Transformer \cite{liu2021swin}.

\paragraph{Cosine normalized attention.}
Rather than scaled dot-product attention, we use cosine attention with a learnable per-head scaling factor:

\begin{equation}
    A_{ij}^{(h)} = \tau^{(h)} \cdot \frac{\mathbf{q}_i^{(h)}}{\|\mathbf{q}_i^{(h)}\|} \cdot \frac{\mathbf{k}_j^{(h)}}{\|\mathbf{k}_j^{(h)}\|},
\end{equation}

where $h$ indexes the attention head, and $\tau^{(h)} = \exp\!\left(\min\!\left(\lambda^{(h)},\, \ln 100\right)\right)$ is a learned, clamped temperature parameter initialised to $\tau^{(h)} = 10$. The clamping ensures $\tau^{(h)} \leq 100$, preventing attention collapse to a hard argmax. The choice of this attention mechanism is motivated by improvements in training stability and convergence speed for deep networks, as well as better generalisation performance shown in the improved second version of the Swin Transformer. \cite{Liu2021SwinV2}  \cite{LuoCosineNormalization2017}

\paragraph{Continuous relative position bias.}
Rather than a discrete relative position bias table, we follow the style of the improved Swin Transformer and use a small MLP to generate biases from normalised, log-scaled relative coordinate offsets. For a pair of tokens at positions $(i, j)$ within the window, the 2D relative offset $\Delta\mathbf{r}_{ij} \in \mathbb{R}^2$ is first normalised by the window size and then mapped through a log-linear compression:

\begin{equation}
    \tilde{\Delta r} = \operatorname{sign}(\Delta r) \cdot \frac{\log_2(|\Delta r| + 1)}{\log_2 8},
    \qquad \Delta r \in \{-(w-1), \ldots, w-1\}.
\end{equation}

The compressed offset is fed into a two-layer MLP with a single hidden layer of size 512 to yield per-head biases:

\begin{equation}
    \mathbf{b}^{\text{cpb}}(\Delta\mathbf{r}_{ij}) = W_{\text{cpb},2}\,\operatorname{ReLU}\!\left(W_{\text{cpb},1}\,\tilde{\Delta\mathbf{r}}_{ij}\right) \in \mathbb{R}^{H_{\text{heads}}}.
\end{equation}

The bias is then passed through a sigmoid and scaled to the range $[0, 16]$:

\begin{equation}
    B^{(h)}_{ij} = 16 \cdot \sigma\!\left(\mathbf{b}^{\text{cpb}}_{h}(\Delta\mathbf{r}_{ij})\right).
\end{equation}

\paragraph{Attention output.}
The full pre-softmax attention logit for head $h$ is:

\begin{equation}
    \hat{A}^{(h)}_{ij} = A^{(h)}_{ij} + B^{(h)}_{ij}.
\end{equation}

After applying softmax over the key dimension, the output for head $h$ is:

\begin{equation}
    \mathbf{O}^{(h)} = \operatorname{softmax}\!\left(\hat{\mathbf{A}}^{(h)}\right) \mathbf{V}^{(h)}.
\end{equation}

The outputs of all heads are concatenated and projected:

\begin{equation}
    \mathbf{O} = \left[\mathbf{O}^{(1)} \;\|\; \cdots \;\|\; \mathbf{O}^{(H_{\text{heads}})}\right] W^O.
\end{equation}

\paragraph{Spatial Swin block residual structure.}
A full Spatial Swin block applies windowed attention followed by a feed-forward MLP, both with pre-norm and residual connections:

\begin{align}
    \mathbf{X}' &= \mathbf{X} + \operatorname{LN}\!\left(\operatorname{WA}(\mathbf{X})\right), \\
    \mathbf{X}'' &= \mathbf{X}' + \operatorname{LN}\!\left(\operatorname{MLP}(\mathbf{X}')\right),
\end{align}

where $\operatorname{WA}(\cdot)$ denotes the windowed attention operation described above and $\operatorname{MLP}(\cdot)$ is a two-layer feed-forward network with hidden dimension $\lfloor d \cdot r \rfloor$ and expansion ratio $r = 4$.

\subsection{Temporal Self-Attention}

After each spatial attention stage, a dedicated temporal attention block operates independently on the time dimension for each spatial token. Given the sequence of embeddings at a fixed spatial location $n$, arranged as $\mathbf{X}_n \in \mathbb{R}^{T \times d}$, temporal attention is computed with the same cosine formulation \cite{LuoCosineNormalization2017} and a per-head learnable temperature $\tau_{\text{temp}}^{(h)}$:

\begin{equation}
    A^{(h)}_{\text{temp},st} = \tau^{(h)}_{\text{temp}} \cdot \frac{\mathbf{q}_s^{(h)}}{\|\mathbf{q}_s^{(h)}\|} \cdot \frac{\mathbf{k}_t^{(h)}}{\|\mathbf{k}_t^{(h)}\|}.
\end{equation}

\paragraph{Temporal relative position bias.}
A scalar relative position bias is computed from log-compressed relative time offsets. For relative temporal offset $\delta = s - t \in \{-(T-1), \ldots, T-1\}$:

\begin{equation}
    \tilde{\delta} = \operatorname{sign}(\delta) \cdot \frac{\log_2(|\delta| + 1)}{\log_2 2},
\end{equation}

and the bias for head $h$ is a directly learnable lookup:

\begin{equation}
    b_{\text{temp},h}(\delta) = \mathbf{B}_{\text{temp}}\!\left[\delta + T - 1,\, h\right],
\end{equation}

where $\mathbf{B}_{\text{temp}} \in \mathbb{R}^{(2T-1) \times H_{\text{heads}}}$ is a registered buffer populated from the log-compressed offsets at initialisation and not updated during training.

\paragraph{Attention masking.}
Depending on the configuration, an optional causal mask may be applied. In the \emph{custom} masking scheme, tokens in the conditioning window $[0, T_c)$ are prevented from being attended to by predicted tokens $[T_c, T)$ to preserve conditioning information throughout the network. The mask is defined as

\begin{equation}
    \mathbf{M}^{\text{custom}}_{st} = \begin{cases} -\infty & \text{if } s < T_c \text{ or } t < T_c,\\ 0 & \text{otherwise,} \end{cases}
\end{equation}

and enforces strict separation between the conditioning and prediction windows. 

\paragraph{Temporal block residual structure.}
The temporal block reshapes the representation to $\mathbb{R}^{(B \cdot N) \times T \times d}$, applies attention and a feed-forward MLP with pre-norm and residual connections, then reshapes back to $\mathbb{R}^{B \times T \times N \times d}$. Functionally this is the same as the spatial block structure, but with attention and MLP applied along the full temporal dimension instead of spatial windows.

\subsection{Hierarchical Patch Merging and Expansion}

\paragraph{Patch merging.}
At each encoder depth transition, four spatially adjacent tokens are concatenated and linearly projected to halve the token count while doubling the embedding dimension:

\begin{equation}
    \mathbf{z}_{\text{merged}} = W_{\text{merge}} \begin{bmatrix} \mathbf{z}_{2i,2j} \\ \mathbf{z}_{2i+1,2j} \\ \mathbf{z}_{2i,2j+1} \\ \mathbf{z}_{2i+1,2j+1} \end{bmatrix},
    \qquad W_{\text{merge}} \in \mathbb{R}^{2d \times 4d}.
\end{equation}

This reduces the token map from $(\hat{H}, \hat{W})$ to $(\hat{H}/2, \hat{W}/2)$ and increases the embedding dimension from $d$ to $2d$.

\paragraph{Patch expansion.}
The reverse operation first doubles the channel dimension with a linear layer, then rearranges channels back into spatial positions:

\begin{equation}
    \mathbf{z}_{\text{exp}} = W_{\text{unmerge}} \, \mathbf{z}_{\text{bottleneck}},
    \qquad W_{\text{unmerge}} \in \mathbb{R}^{2d \times d},
\end{equation}

followed by a pixel-shuffle-style rearrangement that maps the $(2d)$-dimensional channel vector at each token back to a $(d)$-dimensional vector at each of four spatially neighbouring locations, recovering the original resolution.

\paragraph{Skip connections.}
Encoder features at each resolution level are passed to the corresponding decoder level via skip connections. Before fusion, the encoder representation is processed by a ConvNeXt-style block $f_{\text{skip}}$:

\begin{equation}
    \mathbf{x}_{\text{dec}} \leftarrow \mathbf{x}_{\text{enc}} + f_{\text{skip}}(\mathbf{x}_{\text{enc}}).
\end{equation}

The ConvNeXt block \citep{Liu2022ConvNeXt} applies a depthwise spatial convolution, layer normalisation, and a two-layer channel-wise MLP with GELU activation, all wrapped in a residual connection:

\begin{equation}
    f_{\text{skip}}(\mathbf{x})
    =
    \mathbf{x}
    +
    \Gamma \odot
    W_2\,\sigma\!\left(
        \operatorname{LN}\!\left(
            \operatorname{DWConv}_{k\times k}(\mathbf{x})
        \right)
        W_1
    \right),
\end{equation}

where $\operatorname{DWConv}_{k\times k}$ denotes a depthwise convolution with kernel size $k$ applied independently per channel, $\operatorname{LN}$ denotes layer normalisation, $W_1 \in \mathbb{R}^{d \times d_h}$ and $W_2 \in \mathbb{R}^{d_h \times d}$ are learnable pointwise projections with expansion ratio $r = d_h/d = 4$, $\sigma$ is the GELU activation, and $\Gamma \in \mathbb{R}^{d}$ is a learnable per-channel scaling vector. As this skip connection includes spatial convolutions and a residual itself, it allows for a more flexible fusion of encoder and decoder features while maintaining stable gradient flow.

Aside from the U-net inspired skip connections, the architecture also includes residual connections around each full sequence of space-then-time attention blocks. As the length-wise skip connections realise gradient flowthrough from encoder to decoder, these residual connections allow for gradient flow through the depth of the network. This dual axis information flow promotes complex modelling of spatiotemporal dependencies while maintaining stable training dynamics and preserves information quality across the whole network.

\subsection{Flow-Time Conditioning (Flow-Matching Model Only)}

The flow-matching model introduces an additional conditioning signal: a scalar flow-time $\tau \in [0, 1]$ that parameterises the integration path from the prior to the data distribution. Flow-time is embedded via a high-dimensional sinusoidal encoding. For embedding dimension $d_\tau$, the sinusoidal features are:

\begin{equation}
    \boldsymbol{\phi}(\tau)_k = \begin{cases}
        \sin\!\left(\tau \cdot \omega_k\right) & k \leq d_\tau/2, \\
        \cos\!\left(\tau \cdot \omega_{k - d_\tau/2}\right) & k > d_\tau/2,
    \end{cases}
    \qquad \omega_k = 10000^{-2k/d_\tau}.
\end{equation}

This is then processed by a two-layer MLP with SiLU activations to produce a conditioning vector $\mathbf{c}(\tau) \in \mathbb{R}^{d}$, which is concatenated onto the token sequence at the start of each Space-Then-Time attention block sequence:

\begin{equation}
    \tilde{\mathbf{Z}} = \left[\mathbf{c}(\tau) \;\|\; \mathbf{Z}\right]_{\text{sequence}},
\end{equation}

so that flow-time information is available to both spatial and temporal attention at every depth of the network. After the attention blocks, the conditioning vector is removed before proceeding to the next stage. At the new stage, the flow-time embedding is re-concatenated again, ensuring that temporal conditioning is consistently integrated throughout the network.


\section{Deterministic Models}

\subsection{Prediction}

The deterministic model receives as input a sequence of the past five velocity field states and directly predicts the next five states. Due to the grouping of five subsequent states of the system, we aim to reduce the amount of compounding error from recursive inference.


\subsection{Architecture Overview}

The deterministic model uses the shared backbone described in the previous section. It operates on the same patchified spatiotemporal representation and produces a direct mapping from past states to subsequent future states.

\section{Flow-Matching Models}

\subsection{Prediction}

The flow-matching model conditions on the same five past velocity field states as the deterministic model. In addition, it concatenates a noise sample drawn from a prior distribution. The model learns to predict a velocity field that transforms the noisy sample into a physically consistent future state. Note that the term velocity does not refer to the physical velocity of the Navier-Stokes flow, but instead refers to the flow from noisy distribution to the learned distribution of subsequent states. Even though the model architecture itself is still deterministic, the nature of sampling from the prior distribution makes this model a probabilistic model.

\subsection{Flow-Time Conditioning}

Flow-time is encoded using a high-dimensional sinusoidal embedding, which is processed by an MLP with SiLU activations. This embedding is reintroduced with concatenation onto the embeddings at each start of the Space-Then-Time attention block sequence. This ensuring that temporal information is available throughout the network and is not lost during the attention processes.

\subsection{Prior Distribution Construction}

The prior distribution is generated by applying a Gaussian filter to pure Gaussian noise. This introduces spatial and temporal correlations, resulting in a structured noise field. The standard deviations for the Gaussian filter are set to 4 in spatial dimensions and 1 in the temporal dimension, based on empirical tuning and domain knowledge. Essentially, the Gaussian filter over the raw Gaussian noise acts as a low-pass filter resulting in a easier learning problem and thus decreasing the amount of time required for the model to converge while training. 

\subsection{Sampling and Integration}

The model predicts a velocity increment field conditioned on flow-time. The final predicted state is obtained by integrating this velocity field over flow-time using a numerical integration scheme. We use a standard euler-integration scheme with 20 steps, as it was found that using more steps did not significantly improve performance while drastically increasing computational cost. 

\subsection{Architecture Overview}

The flow-matching model shares the same backbone architecture as the deterministic model, with the primary difference being the inclusion of flow-time conditioning and noise input.

\section{Model Scaling and Architectural Variants}\label{sec:model_variants}

Both modeling approaches are evaluated under two architectural regimes. One configuration uses smaller patch sizes with higher embedding dimensions and deeper networks, while the other uses larger patch sizes with reduced embedding capacity. The size of mlp layers is adjusted accordingly to maintain a consistent computational budget for its patch size. Additionally, the number of space-then-time attention blocks per layer is varied as a hyperparameter to control computational cost and define less difference in representational capacity between the \texttt{d2} and \texttt{d3} models for comparability of the models. These choices allow us to investigate the trade-off between fine-grained spatial resolution and global contextual reasoning. 

Note that patch fusion results in a double size embedding dimension and fourfold pixel size receptiveness, thus making the second depth embeddings of the \texttt{d3} models and the first depth embeddings of the \texttt{d2} models equivalent in size and pixel-correspondence. The \texttt{d3} models essentially start from a more localised representation, while the \texttt{d2} models start from a more globalised representation.
