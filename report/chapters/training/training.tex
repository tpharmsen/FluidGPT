\subsection{Training procedure}
\begin{comment}
Training Framework and System Abstraction

To support large-scale experimentation across heterogeneous compute environments, we developed a custom training framework designed to seamlessly operate on both local devices and high-performance computing (HPC) systems. In particular, the framework targets SLURM-managed, container-based clusters while retaining full compatibility with single-node and multi-GPU setups. This abstraction enables identical training and validation logic to be reused across environments, ensuring reproducibility and minimizing environment-specific code paths.

The framework is fully modular and configurable through declarative configuration files, allowing model architectures, optimization parameters, data handling, and distributed training settings to be adjusted without modifying core training code. This design was critical for systematically comparing multiple model classes under controlled experimental conditions.

\end{comment}
\paragraph{Model Training}

Four foundation models were trained within this unified framework. The first is a deterministic autoregressive (AR) model, which predicts the next temporal state conditioned on a fixed history window. The second is a probabilistic flow-matching model, which learns a conditional distribution over future states and enables stochastic sampling during inference. For the flow-matching model, the prior-distribution is generated on the go with correlated gaussian noise. The noise is generated as pure gaussian noise, with a gaussian filter with a standard deviation of 4 in spatial directions and 1 in temporal direction applied to introduce correlation. Applying spatial-correlation of the prior distribution is not only reducing the sharpness of interfaces in the fluids, but also reduces the state-space from which the model has to learn to transform to the target distribution, making the learning task easier.

\paragraph{Optimization and Learning Rate Scheduling}

Both models were trained using the same optimization strategy to ensure a fair comparison. Learning rates were tuned using a schedule consisting of an initial warmup phase, followed by stepwise decay at predefined milestones. The warmup phase mitigates optimization instability during early training, particularly for large models and distributed settings, while milestone-based decay improves convergence during later stages of training. Due to the sampling nature of the flow-matching model, a slightly higher initial learning rate was used compared to the deterministic AR model. Also, the flow-matching models are trained for longer at pre-decay learning rates to account for the increased complexity of learning a conditional distribution. All training is done with bfloat16 reduced precision to balance computational efficiency with numerical stability.

\paragraph{Hardware Platform and parallelism}

All large-scale experiments were conducted on the state of the art NVIDIA DGX B200 unified AI platform, leveraging its high-bandwidth interconnect, large GPU memory capacity and high compute power. Training and evaluation were executed within containerized environments, ensuring consistent software dependencies across runs. Training was performed using data parallelism across 8 devices, resulting in an effective batch size equal to eight times the per-device batch size of 176. This parallelism was essential to stabilize optimization and maintain throughput given the high-dimensional spatial-temporal data and large model capacity.

For each dataset, 20\% of the available trajectories were reserved for validation and were not used during training. All validation metrics were computed exclusively on this held-out split. Validation was designed to assess both short-term predictive accuracy, long-horizon temporal stability and physics spectral correctness of the learned dynamics. The metrics that will be used are the per-sample relative root mean square error (RRMSE) and the per-sample relative absolute error (RAE), which are defined as


\begin{equation}
\text{Per-sample relative RMSE} = \frac{1}{N} \sum_{i=1}^{N} \sqrt{\frac{\left( y_i - \hat{y}_i \right)^2}{y_i^2}}
\end{equation}

\begin{equation}
\text{Per-sample relative absolute error} = \frac{1}{N}\sum_{i=1}^{N} \frac{ \left| y_i - \hat{y}_i \right|}{\left| y_i \right|}
\end{equation}

where $y_i$ is the ground truth value and $\hat{y}_i$ is the predicted value for the $i$-th sample, and $N$ is the total number of samples. These metrics provide a scale-invariant measure of prediction error, allowing for meaningful comparison across different datasets and model configurations. All validation is done in float32 precision to prioritize accurate error measurement over computational efficiency.


\subsubsection{Model- and dataset-specific Validation}

\paragraph{Deterministic Model.}
The deterministic autoregressive (AR) model produces a static prediction for a given input sequence. Both single-step and rollout validations therefore yield a deterministic predicted trajectory, which is directly compared against ground truth using pointwise and spectral physics metrics. The model can trivially be used in autoregressive fashion by feeding in the output timeblock as input timeblock.

\paragraph{Flow-Matching Model.}
The probabilistic flow-matching model defines a conditional distribution over future states. During validation, 16 independent samples were drawn for each input sequence. For the single next-timeblock validation of the Amira dataset a reduced amount of 8 samples were drawn. The distribution of error values is calculated in per-sample fashion and aggregated across samples to analyze the variability in predictions. 

As the flow-matching model predicts \emph{velocity increments} rather than absolute states, to generate the next physical state, a sample is first drawn from a prior distribution. This sample is then integrated forward in \emph{flow-time} using the learned velocity field (the model), conditioned on the current physical state. Here, \emph{flowtime} $t_f$ is an auxiliary, continuous variable that parameterizes the transformation from the prior distribution to the predicted physical state. Formally, given an distribution $x_0$ and a learned velocity field $v_\theta(x,t)$, the integration in flowtime is expressed as
\begin{equation}
    x(1) = x(0) + \int_{0}^{1} v_\theta\bigl(x(t_f), t_f\bigr) \, d{t_f},
\end{equation}
where $T$ is the end of the flowtime interval. This continuous integration transforms the sample into a prediction in physical space. For the validation, we employed a simple Euler integration scheme with 20 discrete flowtime steps to approximate this integral. The prior distribution used in validation is the same as during training.

Once a sample is transformed into a physical state, it can be fed back as conditioning-input to the model to generate subsequent predictions, enabling autoregressive rollouts. 

\subsubsection{Single-Step Validation}
As an initial evaluation, both models were assessed using a single next-timeblock prediction setting. Given a ground-truth input sequence, the models predict the immediate next temporal block without feeding back their own predictions. This evaluation isolates the one-step transition accuracy and avoids error accumulation effects inherent to autoregressive rollouts. Thus this next-timeblock error metric consists of the average per-sample error of the next 5 timesteps over all the input-output pairs of the validation dataset.

\subsubsection{Rollout Validation}
To evaluate long-term behavior, both models were deployed in an autoregressive rollout configuration. Starting from the first 5 physical states of each validation trajectory, model predictions were recursively fed back as inputs to generate future states. Prediction errors were computed at each timestep throughout the rollout horizon, enabling analysis of stability over time. 

\subsubsection{Spectral Diagnostics}
In addition to pointwise errors, validation focused on physically motivated spectral diagnostics. For each predicted and ground-truth state, the log-scaled kinetic energy spectrum $E(k)$ and enstrophy spectrum $Z(k)$ were computed by Fourier transforming the velocity field and aggregating contributions over isotropic shells in wavenumber space. 

Scale-resolved spectral errors were defined as
\begin{equation}
\varepsilon_E(k) = \left| \log E_{\mathrm{pred}}(k) - \log E_{\mathrm{true}}(k) \right|,
\qquad
\varepsilon_Z(k) = \left| \log Z_{\mathrm{pred}}(k) - \log Z_{\mathrm{true}}(k) \right|,
\end{equation}
allowing direct comparison of model fidelity across spatial scales.
